RoomDTO enrichment (list + get + write responses)

Persisted columns are mapped from room. After load, RoomService.enrich* attaches inventory summaries from room_equipment where status = OK:

FieldSourceFE use
equipmentCategories[] Distinct equipment.category Filter ?equipmentCategory= (AND). Do not show as tag labels — use equipmentNames.
equipmentNames[] Distinct equipment.name (ordered) Timeline tags, booking Select labels, tooltips — e.g. “Micro không dây”, “Máy chiếu Full HD”.

Inventory đầy đủ (mọi status, gồm BROKEN) chỉ có trên GET /api/rooms/{id}/equipment — JSON array, không phải Page. FE 3D: gọi inventory; nếu fail (trừ abort) thì fallback equipmentNames / categories trên RoomDTO.

Backend phải làm (không tùy chọn)
  1. Chạy Liquibase: cột room.layout_type, floor_width_m, floor_depth_m; enum Java + DB MICROPHONE; seed/update catalog micro category=MICROPHONE (không để OTHER nếu tên là “Micro không dây”). Restart BE sau changelog mới.
  2. Mọi RoomDTO (GET list, GET id, POST/PUT/PATCH response): luôn gắn equipmentCategories[] và equipmentNames[] từ room_equipment status=OK thôi. Hai field này không persist. Body write từ FE nếu gửi hai array này thì bỏ qua.
  3. GET /api/rooms?equipmentCategory= lặp được; AND: phòng phải có inventory OK cho mỗi category gửi lên. Giá trị đúng enum: PROJECTOR DISPLAY AUDIO VC MICROPHONE OTHER.
  4. Write room: nếu thiếu layout/floor thì default layoutType=STANDARD, floorWidthM=6.00, floorDepthM=4.50. Không suy floor từ capacity.
  5. PATCH /api/rooms/{id}: FE luôn gửi id trong body (= path). Status-only: { "id", "isActive" } — không đụng lock. Form: gửi đủ field + lockedDepartment: { "id": n } hoặc null (public/unlock). BE: nếu body thiếu id thì gán từ path; path ≠ body.id → 400 idinvalid. Form PATCH (name có mặt) gọi resolveLockedDepartment cả khi null.
  6. JSON lock: lockedDepartment (object), không có lockedDepartmentId. vipAmenities = CSV code VIDEO_4K,SOUNDPROOF,CATERING,DEDICATED_SUPPORT,PRIVACY_GLASS.
  7. GET /api/rooms/{id}/equipment trả toàn bộ dòng inventory (OK + BROKEN + RETIRED), mỗi phần tử có equipmentName.
