2

Authenticated

3

Request

Interceptor gắn Authorization: Bearer …. Ngrok header khi base URL trực tiếp ngrok.

4

401

emitAuthLogout() → AuthLogoutListener → logout() + navigate("/login").

5

Profile refresh

Mở ProfileDialog luôn GET /account (+ pending dept) — không tin cache login.

useAsyncFetch

Effect + refetch chung một AbortController. Ignore abort error. Dùng cho hầu hết feature hooks.

Hand-rolled abort

useRoomSchedule, useNotifications (poll 300s) — cùng kỷ luật abort.

Server tables

DataTable serverSide + useServerTableQuery → Spring page/size/sort (+ q). Rooms, users, bookings, invoices, revenue by-room.
