Cách đọc guide này
  1. Demo trước (mục 1) → biết sẽ show gì.
  2. Bản đồ + kiến trúc (2–3) → định vị file.
  3. Auth + nghiệp vụ (4–5) → kể được flow.
  4. Q&A + gotchas (7–8) → luyện trả lời sâu.
  5. Cheat sheet (9) → quét 2 phút trước vào phòng.

1. Script demo mentor (15–20 phút)

Tick từng bước khi luyện. Mỗi bước có “mentor hay hỏi” — đọc trước khi demo thật.

Edge
Cố tình gây lỗi để chứng minh FE hiểu BE — mentor thích hơn “happy path” suông.
Overlap booking — đặt trùng giờ cùng phòng → toast error.overlap.
File map lỗi: src/lib/api-error.ts
Cancel quá muộn — hủy lịch đã bắt đầu → error.alreadystarted.
USER mở URL admin — gõ /admin/rooms → NoPermission (RequireRole).
Hỏi: Guard nằm ở đâu? → src/app/components/RequireRole.tsx + router.tsx
401 giả lập — xóa token trong DevTools → request tiếp → logout về /login (không window.location).
